Prior Work Insights

已有工作给我们的四个压力测试

01

STRATAGEM 是背景，不是同一问题

STRATAGEM 研究 game training 是否写入权重级 reasoning ability。我们研究的是旧 mega-skill / receipt knowledge 能否在 target test time 被调用、验证或拒绝。

02

Agent KB / ExpeL 是强 baseline

如果 legacy mega-skill knowledge 不能超过等 token 的 workflow memory、raw trajectory retrieval 和自然语言 insight，就只能称为 memory scaffold，而不是 source-specific value。

03

Voyager 提醒我们别把文本当能力

可复用 skill library 的价值来自环境反馈和自验证。我们的旧 mega-skill 文本只能提出 hypothesis；target-native receipts 才能决定它是否真的帮助 reasoning。

04

Trace-to-skill 类工作逼近我们的边界

单纯把轨迹总结成 SOP 已经不够。我们的差异点应落在 mega-skill lineage、receipt validation、matched destructive controls 和 negative-transfer recovery。

Protocol

我们真正需要通过的 gate

  1. Source receipts legacy mega-skill members must be linked back to fresh no-human-hints source rollouts, with transition, replay and intervention receipts.
  2. Source gate recipe candidates must survive shortcut exclusion, blind held-out predictive gain, alpha-renaming invariance and shuffled/control separation.
  3. Target binding target-time reasoning may use the recipe as weak prior; live target receipts support, refute or force SOURCE_OFF.
  4. Matched evaluation legacy mega-skill knowledge must beat target-only, generic, raw trajectory, insight, shuffled and other-source on success or adaptation cost.
