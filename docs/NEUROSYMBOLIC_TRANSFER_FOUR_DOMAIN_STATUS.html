真正实现的 neural-symbolic factorization

Neural 和 symbolic 不是把 LLM 输出改名。Source 侧的 value/structure 必须来自执行过的 intervention； target 侧的 neural component 只负责把当前 observation 与 admissible action 绑定到已冻结的 canonical structure。

七步计划：做到第 7 步后的真实状态

  1. Portable audit。exact registry、compact receipts 与 ALFWorld replay 可 clean-checkout 审计；三域外部 runtime/cache 尚未 vendored。
  2. 四域独立 reserve。aggregate directional gate 通过；ALFWorld/TIR 强确认，DiscoveryWorld 小样本正向，WebShop 强单域 gate 未通过。
  3. ALFWorld multiplicity。identity set 在 6 个 count-two tasks 上 4/6 vs 1/6；正向但仍小样本。
  4. 扩 target scope。TIR rotation 19/21 vs 4/21；DiscoveryWorld Normal 则发现 adjacency vocabulary gap 并出现 0/1 vs 1/1 负迁移。
  5. 学习 latent ontology。Sokoban/Tetris/2048 学到的匿名 roles 在 Candy/Super Mario fresh confirm 未超过 marginal，因此不确认。
  6. Online utility/abstention。one-sided 95% Beta lower bound + exact applicability 在 future-route 层面给出 5 select / 4 abstain；cold start 一律 abstain。
  7. Video event graph。CLEVRER 511/720 vs 489/720（27W/5L）；只确认 synthetic event-graph route，不确认自然视频。
这条演化最重要的 lesson：abstraction 必须与 target 的控制层级同构。 增加更多 rollouts 或更强模型不能修复错误的 symbolic state/action factorization。

证据支持什么，不支持什么

Supported 当前可以写进结论

  • 四域独立 reserve 上 transfer delta 均为正，aggregate directional gate 通过。
  • Target-native neural grounding 与 source symbolic control 可以分离。
  • ALFWorld/TIR 独立复现强通过；DiscoveryWorld Easy 小样本正向且无 regression。
  • Fail-closed dispatcher 能阻止 unsupported route 获得 source authority。
  • 另有 TIR rotation 与 CLEVRER synthetic event-graph 两条正式正结果。

Not supported 仍不能声称

  • 同一个 universal skill 从一个游戏迁移到所有四域。
  • 任意真实游戏、任意 task 或整个 benchmark 已解决。
  • Zero-shot grounding 或自动发现跨域 ontology；本轮 learned ontology 是负结果。
  • WebShop 已被强单域统计复现；它目前是正向但 inconclusive。
  • STAR、NExT-QA、Video-Holmes 或广义自然视频迁移已通过。
  • 达到 benchmark SOTA，或 source provenance 对所有 route 都是必要的。
Operational disclosure：ALFWorld final replay

第一次 final invocation 在完成 target-only、authentic 和两个 shuffled tasks 后因 foreground transport 中断，且没有写 final report。 未修改 artifact、task、threshold、seed 或 policy；随后从头执行完全相同的冻结 deterministic replay。 因此该证据是 frozen deterministic replay，不是 uninterrupted one-shot run。

建议的执行顺序

1
先处理 WebShop replication uncertainty。

保留当前 6W/1L 为 inconclusive evidence；冻结新 reserve，不调 threshold，不把 aggregate 显著性借给单域 claim。

2
学习 state-level applicability。

以历史 route evidence 训练，但当前 task outcome 不能影响自身选择；同时保留 cold-start abstain 和 exact structural fail-close。

3
修 DiscoveryWorld representation，不修 consumed trajectory。

只在 development 加 target-native adjacency；找到 target comparator 非 ceiling 的早期决策点后，再冻结 Normal reserve。

4
缩小 ontology-learning claim。

当前三游戏 pooled roles 在 Candy/Super Mario 未确认；下一轮只学习单个 executable family 内可被 intervention 识别的 causal role。

5
视频从 CLEVRER 向自然视频逐级扩。

先验证 STAR 的 target-native event/identity graph，再考虑 NExT-QA 与 Video-Holmes；不能把 CLEVRER 正结果直接外推。

6
补 full clean-room 与 equal-budget baselines。

vendor 或锁定外部 runtime/cache，并比较 target memory、retrieval、target-written symbolic workflow 和 black-box policy。
