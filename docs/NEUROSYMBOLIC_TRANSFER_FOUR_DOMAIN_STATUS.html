真正实现的 neural-symbolic factorization

Neural 和 symbolic 不是把 LLM 输出改名。Source 侧的 value/structure 必须来自执行过的 intervention； target 侧的 neural component 只负责把当前 observation 与 admissible action 绑定到已冻结的 canonical structure。

七步计划：做到第 7 步后的真实状态

  1. Portable audit。exact registry、compact receipts 与 ALFWorld replay 可 clean-checkout 审计；三域外部 runtime/cache 尚未 vendored。
  2. 四域 reserve audit。ALFWorld/TIR 强确认，DiscoveryWorld 小样本正向；WebShop 被发现只有 13 个循环 semantics，所以旧四域 independent aggregate claim 撤回。
  3. ALFWorld multiplicity。identity set 在 6 个 count-two tasks 上 4/6 vs 1/6；正向但仍小样本。
  4. 扩 target scope。TIR rotation 19/21 vs 4/21；DiscoveryWorld Normal 则发现 adjacency vocabulary gap 并出现 0/1 vs 1/1 负迁移。
  5. 学习 latent ontology。Sokoban/Tetris/2048 学到的匿名 roles 在 Candy/Super Mario fresh confirm 未超过 marginal，因此不确认。
  6. Online utility/abstention。one-sided 95% Beta lower bound + exact applicability 在 future-route 层面给出 5 select / 4 abstain；cold start 一律 abstain。
  7. Video event graph。CLEVRER 511/720 vs 489/720（27W/5L）；只确认 synthetic event-graph route，不确认自然视频。
这条演化最重要的 lesson：abstraction 必须与 target 的控制层级同构。 增加更多 rollouts 或更强模型不能修复错误的 symbolic state/action factorization。

证据支持什么，不支持什么

Supported 当前可以写进结论

  • ALFWorld 与 TIR 的独立 reserve 强通过；DiscoveryWorld Easy 小样本正向且无 regression。
  • Target-native neural grounding 与 source symbolic control 可以分离。
  • WebShop V14 的 56-goal unique-semantic/unique-ASIN live execution preflight 已通过。
  • Fail-closed dispatcher 能阻止 unsupported route 获得 source authority。
  • 另有 TIR rotation 与 CLEVRER synthetic event-graph 两条正式正结果。

Not supported 仍不能声称

  • 同一个 universal skill 从一个游戏迁移到所有四域。
  • 任意真实游戏、任意 task 或整个 benchmark 已解决。
  • Zero-shot grounding 或自动发现跨域 ontology；本轮 learned ontology 是负结果。
  • WebShop 已被独立 32-goal 统计复现；旧两段各自只有同一组 13 个 goal families。
  • STAR、NExT-QA、Video-Holmes 或广义自然视频迁移已通过。
  • 达到 benchmark SOTA，或 source provenance 对所有 route 都是必要的。
