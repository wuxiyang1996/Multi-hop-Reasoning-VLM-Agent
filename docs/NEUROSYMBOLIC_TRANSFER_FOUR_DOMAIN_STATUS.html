真正实现的 neural-symbolic factorization

Neural 和 symbolic 不是把 LLM 输出改名。Source 侧的 value/structure 必须来自执行过的 intervention； target 侧的 neural component 只负责把当前 observation 与 admissible action 绑定到已冻结的 canonical structure。

我们实际做过什么

  1. 跨五个 worktree 审计旧 docs/logs。确认 rollout 数、行为变化和 source context 并不等于 transferable value。
  2. 保留负结果。Sokoban binary effect→ALFWorld、broad TIR effect、DiscoveryWorld Normal coverage、三类 video routes 没有被“修成正例”。
  3. 把 abstraction 降到可执行结构。分别使用 positive-effect guard、typed workflow value 和 anonymous topology program。
  4. 建立 source gate。要求 authentic source structure 在 disjoint source receipts 上超过 shuffled、marginal 和 phase controls。
  5. 冻结 target-native adapter。source 不能读取 target action token，也不能重排 option 内的 concrete actions。
  6. 做 paired target evaluation。绑定 task identity、manifest、runner、config、artifact 与 report hash。
  7. 建立统一 skill library。四条 exact route 通过；unsupported interface 和 capability mismatch 自动 abstain。
  8. 提交可审计证据。compact receipts、结果文档、registry tests 与 22 个 focused tests 已进入 PR 分支。
这条演化最重要的 lesson：abstraction 必须与 target 的控制层级同构。 增加更多 rollouts 或更强模型不能修复错误的 symbolic state/action factorization。

证据支持什么，不支持什么

Supported 当前可以写进结论

  • Game-derived intervention structure 能在四个精确 target interfaces 上带来 paired success gain。
  • Target-native neural grounding 与 source symbolic control 可以分离。
  • Authentic structure 超过 matched shuffled/marginal/phase controls。
  • Fail-closed dispatcher 能阻止 unsupported route 获得 source authority。

Not supported 仍不能声称

  • 同一个 universal skill 从一个游戏迁移到所有四域。
  • 任意真实游戏、任意 task 或整个 benchmark 已解决。
  • Zero-shot grounding 或自动发现跨域 ontology。
  • Video understanding 已通过；video route 当前仍必须 abstain。
  • 达到 benchmark SOTA，或已完成独立 replication。
Operational disclosure：ALFWorld final replay

第一次 final invocation 在完成 target-only、authentic 和两个 shuffled tasks 后因 foreground transport 中断，且没有写 final report。 未修改 artifact、task、threshold、seed 或 policy；随后从头执行完全相同的冻结 deterministic replay。 因此该证据是 frozen deterministic replay，不是 uninterrupted one-shot run。

建议的执行顺序

1
先做 release-grade reproduction。

把四个 compact receipts、所需 frozen artifacts、环境版本和相对路径装成 clean-checkout audit。先保证别人能验证现有 claim。

2
冻结新的 replication reserves。

不要重复消费当前 24/32/8-task sets 作为 confirmatory evidence；预注册四域 aggregate 与 per-domain gates。

3
修 representation，不修 held-out trajectory。

ALFWorld 优先加入 multiplicity/count state；DiscoveryWorld 优先解决 Normal applicability coverage。所有设计只在新 development split 上做。

4
把手写 ontology 变成 learned latent roles。

先选 ALFWorld 这一条做 controlled proof：learned roles 与 hand-designed roles、shuffled roles、target-written workflow 等预算比较。

5
视频保持独立。

在 event detection、temporal identity 和 target-only executor 未稳定前，不把 video 接入已验证四域 registry。
