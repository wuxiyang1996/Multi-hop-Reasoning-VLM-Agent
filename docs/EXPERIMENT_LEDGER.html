Two-Agent Harness: 从“skill transfer”降级到可证伪的 test-time reasoning benefit

当前结论

最诚实的状态是：工程链路已经很强，但科学 claim 还没有过门。source 训练和 skill context 确实会改变游戏 policy 的行为；target Harness 也能在线 interpose、verify、fallback。 但我们还没有看到一个 authentic source-derived object 稳定超过 generic / shuffled / raw receipts controls。

Claim 边界

对象 当前状态 可说什么 不能说什么
source skill / game policy 不作为 transfer object 可作为 source rollout 分层、intervention 条件和 receipt lineage。 不能说 COLLECT→TAKE、游戏动作程序或旧 skill 文本可执行迁移。
Receipt-grounded weak knowledge primary object, 未证明 benefit 控制规律、失败信号、验证流程、适用边界；每次 target 使用都要 live receipt 验证。 不能让 Harness 直接选择、替换或排序 target action。
Exact graph / motif topology strong probe failed so far 保留为严格 ablation 和 source diagnostic。 不能把 post-hoc topology fit 当作 blind prediction 或 reasoning backbone。
Game-trained weights 独立 factorial 可测 G-S - B、G+S - G-S、G+S - G+Rand。 不能自动归因于 reasoning，也不能证明可以跳过 target SFT。
Target-trained / learned Harness 下一方向 可作为快速适应助手：预测、验证、replan、abstain、source-off。 在强 teacher 大模型验证前，不训练小 LoRA 来掩盖机制失败。 
source MDP receipts
  -> weak, falsifiable control knowledge
  -> target-time prediction / verification / source-off
  -> lower adaptation cost only if authentic beats generic, raw, shuffled, and other-source controls

实验时间线

  1. 旧资产审计。 六游戏 best checkpoints、rollouts、旧 mega-skill 可作为 lineage；旧自然语言 skill bank 和 mega-skill family 固定为 LINEAGE_RETRIEVAL_ONLY。
  2. 双 Agent 架构清理。 repo 缩成两个有模型判断能力的角色：Decision Agent 独占环境动作；Motif/Harness Agent 只能提议、 预测、verify、abstain、source-off。确定性 Harness 只做 receipt/schema/hash 审计。
  3. Source rollout 调试。 早期 observer/JSON proposal 方案会干扰 source policy 或使 Qwen 续写 action list，已放弃。 正式路径改为旧 source policy 原生执行，Harness 事后读冻结 receipts。
  4. Phase-1 六游戏长轨迹。 Tetris 确认为 macro action；Candy swap 合法。skill-on/off return 有正有负，但旧数据缺 no-human-hints exclusion receipt，且部分 response 泄漏 critical-action 语言，只能作 discovery diagnostic。
  5. Skill-internal 88-call matrix。 GPT-5-mini 对 11 skill × 8 condition 做 source-only proposal，authentic backbone-eligible 为 0； 所有 eligible graph 都来自 masked、receipt-only、shuffled 或 skill-off controls。
  6. Game-training Phase 1-7 source gate。 Strider POSITION 证明 B/G-S/G+S/G+Rand 会产生 causal influence， 但 exact graph recurrence 与 one-step value gate 失败，Phase 7 未通过。
  7. Fresh no-human-hints source collection。 Strider/Thunder 各 12 episodes × 100 steps 通过机械 integrity audit；这确认有干净 source 搜索空间， 不确认存在通过 blind recurrence 与 h8 value 的 motif。
  8. 四域七 Cell feasibility。 SIV-Bench 移除；ALFWorld、MiniWoB、WebShop、TIR、Video-Holmes 可真实跑； VTB 数据和官方代码存在，但 full-tool/evaluator integration 仍未完成。
  9. ALFWorld one-shot vertical slice。 真实 ALFWorld online loop 跑通，五条件都成功；authentic 比 target-only 慢一步，因此只是机制 smoke。
  10. ALFWorld weak-knowledge pilot。 四个 canonical adaptation artifacts × 四个 qualification tasks × 六条件：authentic 3/4，其余 2/4。 task 0 曾是 clean replication candidate。
  11. Frozen task-0 10-seed replication。 authentic 1/10，generic 2/10；唯一 authentic success 的 seed 上 generic 也成功。task 0 降级为 sampling/prompt variance。
  12. 当前转向。 不扩 unchanged 20 seeds，不做 one-shot claim，不训练 Harness LoRA。下一步先用大模型验证 target-adapted prediction Harness 是否真的能画出 k=0/1/2/4/8 左移曲线。

Learned Harness / target-trained Harness

这里的方向不是让 Harness 学会把游戏 action 映射到 ALFWorld action，而是让它成为一个 receipt-verifiable predictor：给定当前 target receipt、candidate proposal 和少量 adaptation examples， 预测未来 progress / failure / information need，并在 live receipts 反驳时及时 source-off。

为什么旧 Path B 还不够

  • 旧 dataset 主要是一跳 selected-action prediction，不是 h=1/2/4/8 future official progress。
  • OUTCOME_PREDICTION 标签没有足够 success signal，无法学习 long-horizon success predictor。
  • 现有 ALFWorld adaptation trace 多数只有单 proposal，不能评估 action-conditional ranking。
  • 旧 config 已经设计了 k=0/1/2/4 curve，但实验没有真正完成；现在要补 k=8 和大模型 oracle。

下一步 Gate

下一轮的最小 publishable 路线不是继续调 task 0 prompt，而是证明一个更机械的问题： 来自异构 source MDP 的 receipt-grounded experience，能否减少学习 target action-value/progress predictor 所需的 target interactions？

  1. 冻结 prediction schema。 Harness 输出 action/proposal-conditional 的 success/failure/progress/no-progress/source-applicability prediction，horizon 固定为 1/2/4/8。
  2. 补 target data shape。 ALFWorld 至少收集 multi-proposal 或 matched-continuation receipts；没有多 proposal 就只能做 selected-path calibration，无法证明 decision-making benefit。
  3. 先离线 prediction gate。 大模型 Harness 在 k=0/1/2/4/8 adaptation examples 下预测 future official progress； 画 prediction score 与 task performance 曲线。
  4. 再上线 decision gate。 只有 prediction 有增量，才允许 Harness 通过 ADMIT/REPLAN/ABSTAIN 影响 Decision loop； Harness 仍无 target action authority。
  5. 做 source attribution。 authentic 必须超过 target-only、generic、raw receipts、shuffled、other-game。否则结论降级为 target-trained Harness 或 generic scaffold。
  6. 再考虑 LoRA。 strong teacher 可行后，用 verified-only records 训练小 Harness；如果 teacher 都不行，不用 LoRA 硬救。

失败时怎么办

结果 解释 转向
target-adapted large Harness 不工作当前 target data/schema 不能支撑预测先修 target receipts、proposal set 和 horizon labels。
target-adapted 有效，source 无增量快速适应可行，但不是 cross-domain source benefit改成 target-trained adaptive Harness claim。
prediction 有效，online decision 无效控制接口有问题，不是 predictor 不会修 ADMIT/REPLAN/ABSTAIN policy 与 fallback budget。
