01 · Transfer object

迁移的不是游戏动作，而是 intervention-grounded program content

一个 skill 在这里被实现为：由 source interventions 支持的 typed operators、transition / partial-order constraints、terminal relation 和 abstention contract。Source action 名称、像素特征、游戏身份和完整 controller 都不是 transfer object。

最准确的方法名： Intervention-grounded symbolic program transfer with target-native neural grounding。

Source 提供

Causal structure

从 matched intervention forks 学到 effect relation、控制流、停止条件和证据不足时的拒绝规则。

Target 提供

Native grounding

从目标文本、图像、视频帧或 native candidates 中绑定实体、关系、effect 与 confidence。

Harness 提供

Safe composition

只有结构匹配、grounder qualified、utility positive 且唯一可执行时才授权，否则回退。

迁移的 invariant

  • operator type 与 effect relation
  • transition / recurrence / composition
  • terminal predicate
  • unique-candidate 与 abstention rule
  • source receipt lineage
≠

不直接迁移的部分

  • source pixels 与 visual features
  • source action tokens / game identity
  • 完整 target policy
  • target reward、gold answer 或 formal success
  • 一个手写 universal controller

02 · End-to-end architecture

六个彼此隔离的 authority

实现的关键不是把模块串起来，而是限制每个模块能看什么、能输出什么。

1 · Source receipts 真实 intervention tuples、effect、next state、lineage hash
2 · Program induction 在 typed hypothesis space 中识别唯一解释
3 · Anonymous IR operators、transitions、terminal、abstention
4 · Target grounder 只绑定 target-native entities、effects 与 confidence
5 · Authorization structure × qualification × past utility
6 · Native executor 唯一可输出 action / answer 的组件 
source data authority       = source observations + interventions only
induction authority         = emit program, never target action
target grounding authority  = bind native evidence, never read formal outcome
selection authority         = emit SELECT_SKILL / ABSTAIN, never action
execution authority         = emit native action after valid authorization
evaluation authority        = open gold/outcome only after receipts are frozen

03 · Source-side implementation

从 rollout 到 source-qualified symbolic program

  1. Instrument source environments. 每一步记录 before state、native candidate actions、selected intervention、after state、reward / terminal、effect 与内容哈希。
  2. 构造 matched candidate forks. 在相同 source state 上执行不同候选，成功与失败 forks 必须都保留；只有成功轨迹无法识别 causal operator。
  3. 匿名化 source vocabulary. action name、游戏名和语义标签不能进入 target；归纳器只读取 typed state/effect endpoints 与 transition evidence。
  4. 在冻结 hypothesis class 内搜索。 找到能精确分离 intervention outcomes 的唯一 operator / transition / terminal / abstention program；零个或多个解释都拒绝。
  5. Source qualification. 用 held-out episodes、fresh reserve、shuffled effect、permuted transition、alpha rename 和 missing-evidence controls 验证。

04 · Shared symbolic representation

统一的是 IR contract，不是一个 canonical controller

每个游戏可以学出不同 program body，但都被包装成相同的 content-addressed envelope。Target router 按 required capabilities 和 program content 选择，不能按 source identity 选择。

Neural-symbolic program contract

Program = {
  typed_operators,
  transition_or_partial_order,
  terminal_predicates,
  abstention_rules,
  neural_probe_specs: {
    input_kind,
    model_artifact_sha256,
    supported_min_score,
    refuted_max_score,
    UNKNOWN band
  },
  source_lineage,
  program_sha256
}

Hard symbolic checks

  • type 与 capability compatibility
  • program / artifact hash consistency
  • candidate uniqueness
  • reachable transition / explicit termination
  • UNKNOWN 必须 fail closed

Neural probe contract

  • 只返回 calibrated score / binding
  • 不写控制流
  • 不看 source identity
  • 不看 formal outcome / gold
  • artifact 与 threshold 冻结

Content-addressed evidence

  • program、grounder、executor 都有 SHA
  • authorization 绑定 task state
  • evaluation 在 runtime receipts 后打开
  • alpha rename 不改变 execution
  • src/motif_transfer/neurosymbolic_ir.py — probe、node、route 与 program validation。
  • structural_ir_applicability.py — source contract 与 target requirement matching。

05 · Target-native neural grounding

06 · Selection, authorization, execution

统一 Harness 的实际决策逻辑

eligible_programs = source_programs where:
  source_intervention_qualified
  and learned_from_(state, action, effect, next_state)
  and target_data_read == false
  and named_policy_template_used == false

selected = unique_structural_match(eligible_programs, target_requirement)

if no unique selected program:
    return ABSTAIN
if target_grounder not qualified or structural predicates not closed:
    return ABSTAIN
if past matched utility <= 0 or authentic does not beat permuted control:
    return ABSTAIN

authorization = SELECT_SKILL(program_sha256, executor_sha256)
native_output = target_native_executor(authorization, grounding, candidates)
无 current-task outcome feedback：当前 task 的 reward、gold 或 official success 不能影响它自己的 route selection。Utility calibration 只能来自更早、已经完成且冻结的 matched trials。

Harness 可以输出

  • SELECT_SKILL 或 ABSTAIN
  • selected program hash
  • target executor identity / hash
  • utility 与 authenticity lower bound
  • 结构化 reason 与 authorization receipt

只有 executor 可以输出

  • WebShop native action
  • ALFWorld command
  • DiscoveryWorld operation
  • TIR / video answer slot
  • MiniGrid anonymous recovery token
  • src/motif_transfer/unified_transfer_runtime.py — route validation、utility/authenticity gating 与 authorization。
  • unified_neurosymbolic_harness.py — structural selection 与 target execution handoff。

07 · Adding a new target domain

实现一个新 target adapter 的标准流程

新领域不能从“把 source prompt 塞进去”开始。先定义 target MDP / QA interface，再证明 native grounding 可测。

  1. 写 target interface contract。定义 observation、native candidates、正式 outcome、interaction budget，以及哪些信息 runtime 永远不可读。
  2. 定义 IR requirement。列出目标能够 ground 的 capabilities、typed entities/effects、terminal relation；不要写 source game 名或 action 映射。
  3. 构建 target-native grounder。只在 development/adaptation tasks 上训练或调 prompt；记录模型、数据、threshold 与 artifact SHA。
  4. 做 intrinsic qualification。在 fresh qualification 上测 coverage、covered accuracy、calibration、unique binding 与 abstention；不通过就不能打开 formal reserve。
  5. 实现 native executor。输入只能是 authorization、grounding receipt 和 native candidates；验证 executor 不接受 source token 或 gold。
  6. 冻结 matched condition matrix。至少包含 neural-only、source-induced、source-permuted/shuffled、generic scaffold、target-written isomorphic ceiling。
  7. 运行 untouched formal。先原子写 runtime receipts，再打开 evaluator；按 paired row / task / cluster 统计 wins、losses、ties 与 negative-transfer rate。
  8. 注册 route。只有所有 gates 通过，才把 source program、grounder、executor 与 evidence report hashes 加入 skill library。
必须预注册的 formal gates
  • target selection 与 split 在 outcome call 前冻结。
  • source induction 读取零 target trajectories / outcomes。
  • target grounder qualification 先于 formal reserve。
  • 未授权样本逐项保持 identical baseline fallback。
  • authentic 显著优于 destructive source control。
  • negative transfer 不超过冻结上限。
  • alpha rename 不改变执行；source identity 不可见。
  • target-written equivalent 作为 content-vs-provenance ceiling。

如何解释不同类型的 artifact

formal validated

冻结 qualification 后打开 untouched reserve，全部 preregistered gates 通过。

development / consumed

可用于改 grounder、debug 或估计 headroom，不能当新的 confirmatory evidence。

failed / aborted

保留失败 gate、runtime abort 与污染边界；不能删除或用后续阈值重解释。

machine receipt

JSON 中的 hashes、splits、counts 与 gates 是正式 claim authority。

证据支持

  • 正确 symbolic content 可跨语义目标执行。
  • target-native neural grounding 可与 source-induced IR 组合。
  • selective abstention 能限制 negative transfer。
  • 不同 interventions 可归纳不同 program family。
  • source route 可在零完整 target trajectory 下取得结构。
  • AGQA/CLEVRER 的 matched-arm delta 已与 visual-model grounding 隔离。

证据不支持

  • source provenance 本身造成额外 execution gain。
  • 任意游戏 skill 可迁移到任意领域。
  • target perception 可以从游戏直接迁移。
  • AGQA 已解决全部 669k questions。
  • 已经验证 broad multi-step video MDP transfer。

视频表的结论严格条件化于 benchmark-native shared structured grounding；它不声称 raw-pixel video QA 或视觉感知已经解决。CLEVRER 的 absolute accuracy 仍依赖冻结 neural proof grounder；同题各 arm 共用相同 receipt 只保证它不混淆 paired delta。CLEVRER 对 generic scaffold 的 13W/6L 为正但未达显著；AGQA 的 target-written isomorphic controller 与 source-induced 相等，因此不能证明 source provenance 必要。详细结果：四域统一结果、 V31 prospective result、 two-video grounding-isolated primary、 自然视频 stop result。

12 · AGQA full-family typed transfer

早期 selective AGQA 结果已扩展并通过 fresh 六臂 formal gate

Source-only induction 得到 15 个 typed operators 与 32 条 composition edges，再由 AGQA-native question compiler 和 official-STSG executor 执行。在 2,400 个 fresh questions 上，source-induced 为 2,320/2,400（96.67%），neural-only 为 1,945/2,400，generic scaffold 为 1,950/2,400。Source 对 generic 为 374W/4L（p=2.75e-105），所有预注册 gate 均通过。

因果解释：source-induced 与 target-written-isomorphic 完全一致（0W/0L），而 source-permuted 与 generic 都不能复现增益。因此起作用的是 program content，不是 source identity； source induction 的价值是无需 target-outcome controller tuning 即可恢复这份结构。
边界：这是复用 videos 和 official STSG 的 2,400-question fresh-outcome sample，不能写成 full official-test、raw-video SOTA 或 video-disjoint。详见 V1 hash-bound 报告。

13 · AGQA Layer B raw-video transfer

在共享冻结感知下，游戏归纳的 ordered-effect skill 显著改善最终视频 QA

新的 video-disjoint typed-temporal replication 从真实 Charades 视频开始，经共享的 Qwen3-VL-32B 48/96-frame grounder、SlowFast、operator-free semantic parser、typed executor 与 Qwen3.5-9B fallback，只替换 symbolic Harness。在 256 个 fresh task/video 上， source-induced 为 135/256（52.73%），neural-only 与保持 operator/edge 数量的 source-permuted 均为 106/256（41.41%）：34W/5L，p=2.43e-6， negative-transfer loss 为 1.95%。

允许的结论：game-acquired ordered-effect structure selectively transfers to raw-video temporal/duration reasoning under shared frozen perception。Source-permuted 未复现增益， target-written-isomorphic 与 source 完全等价，因此有效变量是正确的 program composition。
边界：unrestricted generic target-VM scaffold 为 149/256，高于 source；所以不能声称 source policy 优于更宽的 target-engineered controller，也不能称为 full-distribution AGQA2 或 video SOTA。详见 Layer B hash-bound 结果。
