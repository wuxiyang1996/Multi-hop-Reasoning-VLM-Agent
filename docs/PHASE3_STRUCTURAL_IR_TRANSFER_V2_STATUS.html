为什么 TIR 结果 non-trivial

旧 topology artifact 的规则是手写的，所以没有纳入新 claim。V3 重新从 Sokoban tuples 归纳 program，并在 72 个新 source episodes 上确认；随后审计所有历史 TIR allocations，在看 prompt/image/answer/outcome 前冻结剩余 27 个 maze IDs。9-task qualification 一次通过后，未改 code 或 threshold，才解锁 18-task formal。

Target neural binder 只绑定视觉 R/L/U/D relations 和 start/goal entities；source program 只提供重复 typed transition、goal relation 和 abstention。Relation-permuted control 回落到 6/18，authentic 提升到 12/18，说明 program 的 relation structure 而非“有一个 source 标签”产生差异。

ALFWorld 的边界

Grounder 本身在 development 上合格：ADD/REMOVE F1=1.0，entity F1=0.902，destination F1=0.939，shuffled macro F1=0.0125。72-task extension 中 source 为 22/72、neural 20/72，但 source-permuted 同样为 22/72；source vs permuted 为 1W/1L。因此它是安全的小收益，不是 source-specific transfer validation。

Claim boundary：已证明的是两类结构匹配 target 上的 shared-IR neural-symbolic transfer；没有证明 source provenance 必要、任意 domain 通用、视频可直接复用 maze dynamics，或历史 24/24 mechanism cells 都有 powered success gain。
