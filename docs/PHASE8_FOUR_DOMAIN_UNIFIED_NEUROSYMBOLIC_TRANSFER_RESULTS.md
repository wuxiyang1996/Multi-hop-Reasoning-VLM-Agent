## “统一”具体指什么

统一的不是一个手写 canonical controller，也不是把 Sokoban action 搬到所有 target。
统一的是同一条带证据约束的运行协议：

```text
source (state, action, effect, next_state)
  -> source-only typed program induction
  -> anonymous structural applicability
  -> calibrated utility/authenticity authorization
  -> target-native neural grounding
  -> target-native executor
  -> native action
```

不同 route 可以归纳出不同 domain function：

- WebShop 和 TIR 使用 source-induced recurrent relational program；
- DiscoveryWorld 使用 source-induced counted partial-order program；
- ALFWorld V13 使用 source-induced goal-acquisition + recurrent relation program。

共同约束是 selector 只能选择 symbolic program，不能输出 target action；source action
名称、坐标、对象名称和 target outcome 都不能进入 transfer interface。只有本域 neural
grounder 与 executor 能把 typed obligation 变成本域动作。

## ALFWorld 为什么不再 abstain

Phase 7 拒绝的是旧的
`minigrid-put-near-to-alfworld-multiplicity-v2` route。它只有 `2W/0L/70T`
对 neural、`1W/1L/70T` 对 source-permuted，因此继续保留为正确的 abstention；Phase 8
没有改写这条 negative result。

新 route 是
`sokoban-goal-acquisition-to-alfworld-multiplicity-v11`。Source 端从 intervention
tuples 自动归纳出：

```text
UPDATE ENTITY_RELATION / POSITION
UPDATE CONTROL_STATE / POSITION
UPDATE POSITIVE_EFFECT_BINDING / CANDIDATE_CARDINALITY
UPDATE ENTITY_GOAL_RELATION / RELATION_COVERAGE
```

其中关键结构是先通过匿名 state update 让 positive relation binding 从 `0 -> 1`，再执行
recurrent goal relation；无法满足 typed cardinality/handle contract 时 abstain。没有继续提供
`EXPLORE/BACKTRACK/COMMIT` 模板。Fresh source confirmation 为 476/476 transition
conformance，shuffled-effect exact binding 为 0/476。

V10 consumed development 提供 route calibration：`7W/0L/17T`。因此 V13 的 unified
harness 在看当前 reserve outcome 前已经可以授权这条 route。

## V11/V12 为什么不算最终 formal

最初八任务 V11 run 发现 ALFWorld batch 会重排输入 game IDs，而 runner 在 reset 前绑定了
receipt identity。所有 raw 和两个 authentic outcome 暴露后才发现，因此 V11 被中止并保留
abort receipt。V12 只修正 reset 后 identity binding，结果为：

- raw `4/8`；authentic `8/8`；controls `4/8`；ceiling `8/8`；
- `4W/0L/4T`，但 exact `p=0.125`；
- 所以 V12 正确标记为 operational retry / formal gate failed。

它证明链路可运行并给出 power diagnosis，不能事后放宽门槛或称为独立 confirmation。

- `valid_seen` 24/24 和 `valid_unseen` 17/17 multiplicity tasks 已出现在历史 runs；

## 研究边界与下一步

现在可以写：**四条注册的非视频 neural-symbolic route 在统一 harness 下均有显著、
source-specific、零负迁移的 formal evidence。**

仍不能写：任意 game 可迁移到任意 domain、一个 controller 横跨四域、ALFWorld 任意 task
family、四个 ALFWorld ceiling failures 已解决，或 video transfer 已验证。

下一步最有价值的不是再扩大 controller heuristic，而是：

1. 独立复现 ALFWorld V13，或取得真正 OOD 的新 multiplicity tasks；
2. 在 development-only 数据上提高 ALFWorld target-native grounding ceiling，再冻结 threshold；
3. 验证更多 source games 会归纳出不同 program，并能在 target outcome 前预测 applicability；
4. 视频保持暂停，直到 target-native event graph 与 intervention effect 能通过 qualification。
